# CYBER HÉROS v2.5 Ultimate

**Apprends. Joue. Protège-toi.**

Version React + Vite pensée comme un mix entre une structure de missions, une campagne narrative de 5 jours et une expérience de gamification.

## Inclus
- Accueil / tableau de bord
- Campagne narrative 5 jours
- 10 missions libres
- XP, niveaux et badges
- Mini-jeux
- Grand Cyber Challenge de 10 questions
- Certificat imprimable via le navigateur
- Espace enseignant (prototype)
- Mode Parent
- Dark / light mode
- Responsive mobile
- Sauvegarde locale de la progression via `localStorage`

## Lancer
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Le dossier `dist/` peut être déployé sur Netlify, GitHub Pages ou un hébergement statique.

## Pédagogie
Le projet vise une logique **20 % théorie / 80 % interaction**. Les contenus sont rédigés pour un public jeune et adaptés autour de principes d'hygiène numérique. Ils ne reproduisent pas le guide ANSSI.

Le socle de référence fourni pour le projet comporte 42 règles d'hygiène informatique et couvre notamment sensibilisation, authentification, équipements, réseau, nomadisme, mises à jour, supervision et réaction aux incidents.

## Prochaine étape recommandée
Brancher Supabase pour les comptes enseignants, classes, progression, statistiques, badges et sauvegarde des résultats.
